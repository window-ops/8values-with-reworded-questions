# 8values with reworded questions

Note: This is a reworded test to make it more neutral. 8values has a lot of questions that a lot of people, who identify with any label, would not agree, due to being too simplistic. Credit goes to the original authors (https://github.com/8values/8values.github.io).

The 8values Political Quiz measures individuals' political values, including Equality, Nation, Liberty, Tradition, Markets, World, Authority, and Progress.
